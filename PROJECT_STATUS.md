## 🎯 **How to Use Right Now**

### **Immediate Use (Demo Mode)**
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the app
python -m streamlit run app.py

# 3. Open browser
# Navigate to: http://localhost:8501
```

### **Production Use (Real Database)**
1. **Get HarperDB credentials** (Cloud or Local)
2. **Update `config.py`** with your settings
3. **Change `SETUP_TYPE`** from "DEMO" to "CLOUD" or "LOCAL"
4. **Run the app** - same command as above
